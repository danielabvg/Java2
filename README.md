# Java Course – Ejercicios y Prácticas

Este repositorio contiene ejercicios, programas y actividades desarrolladas durante el curso de Java, con el objetivo de reforzar conceptos de programación orientada a objetos, estructuras de datos, manejo de archivos, colecciones, excepciones y buenas prácticas de programación.  
Adicionalmente, se incluye una sección con algunos códigos en Python como apoyo complementario al aprendizaje.

---

## Contenido del Proyecto

- Ejercicios por unidad
- Proyectos y actividades prácticas
- Retos y tareas asignadas
- Código comentado para facilitar el aprendizaje
- Carpeta con scripts en Python relacionados con algunos temas del curso

---

## Requisitos Previos

Antes de ejecutar el proyecto, se recomienda contar con lo siguiente:

**Para Java:**
- Java JDK 17 o superior
- IDE recomendado: IntelliJ IDEA, Eclipse o Visual Studio Code con extensión de Java

**Para Python (si se desea ejecutar los scripts incluidos):**
- Python 3.9 o superior
- Librerías básicas según el contenido de cada script
